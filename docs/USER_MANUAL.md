# Руководство пользователя приложения «ContactBook»

## 1. Введение
Приложение «ContactBook» предназначено для локального ведения телефонной книги, каталогизации персональных и деловых контактов, быстрого поиска и обмена данными в форматах JSON и CSV.

---

## 2. Системные требования
* Операционная система: Windows 10 / 11 (x64)
* Среда выполнения: .NET 8 Desktop Runtime (или выше)
* Место на диске: от 50 МБ

---

## 3. Начало работы
1. Запустите исполняемый файл `ContactBook.UI.exe` или выполните команду запуска из каталога проекта:
   ```bash
   dotnet run --project ContactBook/ContactBook.UI/ContactBook.UI.csproj
   ```
2. При первом запуске приложение автоматически создаст локальную базу данных `contacts.db` в рабочем каталоге и заполнит базовый список категорий («Общие», «Работа», «Семья», «Друзья», «Избранное»).

---

## 4. Основные сценарии использования

### 4.1. Просмотр контактов
* Все сохраненные контакты отображаются в центральной таблице.
* Для просмотра детальной информации кликните левой кнопкой мыши по любой строке таблицы. Данные контакта автоматически отобразятся в правой панели формы.

### 4.2. Добавление контакта
1. Введите обязательные данные в правой панели:
   * **Имя** (обязательное поле).
   * **Телефон** (обязательное поле).
2. При необходимости укажите:
   * **Фамилия**;
   * **Email**;
   * **Группа / Категория** (выбор из выпадающего списка).
3. Нажмите кнопку **«Добавить»**.
4. После сохранения таблица автоматически обновится, а поля ввода очистятся.

### 4.3. Редактирование контакта
1. Выберите контакт в таблице.
2. Измените необходимые поля на правой панели.
3. Нажмите кнопку **«Сохранить»**.
4. Приложение применит изменения в базе данных и обновит строку в таблице.

### 4.4. Удаление контакта
1. Выделите строку контакта в таблице.
2. Нажмите кнопку **«Удалить»**.
3. Подтвердите удаление в появившемся диалоговом окне.

### 4.5. Поиск и фильтрация
* **Поиск:** введите текст в верхнее поле поиска и нажмите кнопку **«Поиск»** (или клавишу Enter). Поиск выполняется регистронезависимо по имени, фамилии, номеру телефона и email.
* **Сброс поиска:** нажмите кнопку **«Сброс»**, чтобы вернуть отображение всех контактов.
* **Фильтр по группе:** выберите нужную категорию в выпадающем списке «Группа:». Список контактов мгновенно отфильтруется.

### 4.6. Экспорт и импорт данных
* **Экспорт в JSON:** нажмите кнопку **«Экспорт JSON»**, выберите папку и имя сохраняемого файла.
* **Экспорт в CSV:** нажмите кнопку **«Экспорт CSV»** для выгрузки контактов в табличном формате, совместимом с Microsoft Excel.
* **Импорт:** нажмите **«Импорт JSON»** или **«Импорт CSV»**, выберите файл. Записи будут добавлены в базу данных с автоматическим присвоением новых уникальных идентификаторов.

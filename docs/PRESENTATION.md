# Презентация проекта: «Записная книжка контактов (ContactBook)»
**Учебный командный проект по теме №10**

---

### Слайд 1: Титульный
* **Заголовок:** Разработка настольного приложения «Записная книжка контактов» (ContactBook)
* **Подзаголовок:** Модульное десктоп-приложение на C# / .NET 8 и Windows Forms с чистой многослойной архитектурой
* **Команда проекта:**
  * Касимов — Тимлид / Архитектор решения
  * Годунов — Backend-разработчик (EF Core, SQLite)
  * Корепанов — Frontend-разработчик (Windows Forms UI)
  * Петухов — QA-инженер / Технический писатель (Unit-тестирование, диаграммы)
* **Визуальное оформление:** Логотип .NET 8, C#, скриншот главного окна приложения.

---

### Слайд 2: Актуальность и цель проекта
* **Проблема:** Необходимость удобного, быстрого и автономного инструмента для систематизации личных и корпоративных контактов без привязки к облачным сервисам.
* **Цель:** Спроектировать и разработать отказоустойчивое настольное приложение с локальной реляционной базой данных, поиском в реальном времени, категоризацией и поддержкой обмена данными (JSON/CSV).
* **Ключевые критерии качества:**
  * Высокая отзывчивость интерфейса (неблокирующий UI за счет асинхронности).
  * Чистая расширяемая архитектура (разделение ответственности слоев).
  * Надежность хранения и целостность данных.

---

### Слайд 3: Стек технологий и инструментарий
* **Платформа и язык:** .NET 8, C# 12 (современные языковые конструкции, nullable reference types).
* **Пользовательский интерфейс:** Windows Forms (WinForms) на современной платформе .NET Desktop SDK.
* **База данных и ORM:** SQLite + Entity Framework Core 8 (`Microsoft.EntityFrameworkCore.Sqlite`).
* **Сериализация:** `System.Text.Json` (поддержка кириллицы UnicodeRanges), потоковый `StreamWriter`/`StreamReader` для CSV.
* **Тестирование:** Microsoft MSTest Framework, MSTest Analyzers.
* **Контроль версий и командная работа:** Git, GitHub, Feature Branch Workflow, Pull Requests, Code Review.

---

### Слайд 4: Архитектура решения (Clean Architecture)
* **ContactBook.slnx** разбит на 4 независимых проекта с однонаправленным графом зависимостей:
  1. `ContactBook.Core` (Домен): сущности `Contact`, `Group`, абстракции `IContactRepository`, `IContactDataService`, бизнес-сервис `JsonContactDataService`. Не зависит ни от каких внешних библиотек.
  2. `ContactBook.Data` (Доступ к данным): реализация `ContactDbContext` на EF Core SQLite, `ContactRepository`.
  3. `ContactBook.UI` (Представление): форма `Form1`, элементы управления, валидация. Зависит **только от интерфейсов Core**.
  4. `ContactBook.Tests` (Модульное тестирование): автотесты домена, репозитория и сервисов экспорта/импорта.
* **Принцип инверсии зависимостей (DIP):** Связывание слоев происходит строго в точке входа (`Program.cs` — Composition Root).

---

### Слайд 5: Проектирование базы данных и ORM
* **Сущности:**
  * `Contact`: `Id` (PK), `FirstName`, `LastName`, `PhoneNumber`, `Email`, `BirthDate`, `Notes`, `GroupId` (FK).
  * `Group`: `Id` (PK), `Name`.
* **Связи и ограничения:**
  * Связь 1:N (одна группа может содержать множество контактов).
  * Внешний ключ с политикой `OnDelete(DeleteBehavior.SetNull)`: при удалении группы контакт сохраняется, группа обнуляется.
  * Первичное сидирование предустановленных категорий («Общие», «Работа», «Семья», «Друзья», «Избранное»).
* **Оптимизация запросов:** Применение `.AsNoTracking()` для операций выборки для исключения накладных расходов трекера EF Core.

---

### Слайд 6: Пользовательский интерфейс и UX-решения
* **Главное окно (Form1):**
  * Таблица `DataGridView` с автоматическим заполнением колонок и выделением строк.
  * Панель быстрого поиска с живой фильтрацией по имени, фамилии, номеру телефона или email.
  * Выпадающий фильтр по группам для мгновенной выборки контактов нужной категории.
  * Боковая панель детальной информации с поддержкой добавления и редактирования записей.
  * Индикатор состояния (`lblStatus`) и динамическая блокировка управляющих кнопок во время выполнения тяжелых операций.

---

### Слайд 7: Асинхронность и обработка данных
* **Асинхронный ввод-вывод (Async/Await):**
  * Все операции с SQLite и файловой системой выполняются асинхронно, что предотвращает зависание UI-потока (UI Thread Freezing).
* **Умный поиск с поддержкой кириллицы:**
  * Устранено ограничение встроенной функции SQLite `lower()`, не поддерживающей регистронезависимый поиск кириллицы без ICU.
* **Обмен данными:**
  * Экспорт и импорт в структурированный JSON с форматированием (интендацией).
  * Экспорт и импорт в CSV с экранированием разделителей и поддержкой дат.

---

### Слайд 8: Обеспечение качества (QA & Unit Tests)
* **Тестовое покрытие (`ContactBook.Tests`):**
  * `JsonContactDataServiceTests`: тестирование сохранения структуры и точности полей при экспорте/импорте JSON и CSV, устойчивость к отсутствующим файлам.
  * `ContactRepositoryTests`: сквозное тестирование CRUD-операций в изолированной временной базе SQLite, сидирования групп, кириллического поиска и каскадных ограничений.
* **Результаты:** 100% тестов проходят успешно (9 из 9 тестов, время выполнения ~1 сек.).
* **Анализ кода:** 0 предупреждений компилятора, строгий режим Nullable Reference Types (`#nullable enable`).

---

### Слайд 9: Командный Git-процесс
* **Модель ветвления:** Feature Branches (`feature/*`).
* **Политика защиты:** Защита ветки `main` (Protected Branch Hook) — любые интеграции производятся только через Pull Request с проверкой и ревью тимлида.
* **Разделение труда:** Четкие границы ответственности исключили конфликты слияния (Merge Conflicts) между UI, Backend и Test-слоями.

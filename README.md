\# Записная книжка контактов (ContactBook)



Учебный командный проект по теме №10: настольное приложение для управления личными и рабочими контактами.

\## Стек технологий

\* Язык и платформа: C#, .NET

\* Интерфейс: Windows Forms (WinForms)

\* База данных: SQLite

\* Тестирование: MSTest / xUnit (Visual Studio Test Explorer)

\* Среда разработки: Visual Studio 2022



\## Архитектура решения (Solution)

\* ContactBook.Core — бизнес-логика, модели данных (Contact, Category) и валидация.

\* ContactBook.Data — слой работы с базой данных SQLite и файлами (JSON/CSV).

\* ContactBook.UI — клиентское приложение Windows Forms.

\* ContactBook.Tests — модульные тесты бизнес-логики и валидации.



\## Основной функционал

1\. Добавление, редактирование и удаление контактов (ФИО, телефон, email, дата рождения, заметки).

2\. Распределение контактов по категориям («Работа», «Семья», «Друзья», «Избранное»).

3\. Быстрый поиск по имени или номеру телефона и фильтрация по группам.

4\. Импорт и экспорт списка контактов.
